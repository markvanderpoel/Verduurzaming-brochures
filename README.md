# Verduurzaming Brochures

This repository stores public supplier brochures, flyers, datasheets and product documents for the Verduurzaming research project.

The private `markvanderpoel/Verduurzaming` repository remains the canonical knowledge base for project knowledge, sources, evidence, claims, product longlists, open questions, todos, Decision Gates and workflow.

This public repository exists so browser/PDF-capable agents can access documents that private GitHub connector tooling cannot read.

Files are provided for research and reference access. Copyrights and trademarks remain with their respective owners. Inclusion does not imply endorsement, recommendation or product selection. Files can be removed on request.

Do not add personal or private documents, invoices, offers, contracts, correspondence, private installation photos or home photos to this repository.

## Contents

- `brochures/`: public supplier brochure, flyer, datasheet and product document files.
- `brochures-index.json`: metadata index with public paths, raw URLs, original private paths, checksums and conservative document metadata.

The index is operational metadata only. Canonical interpretation and project knowledge live in the private repository.
