# Brochure Access

Use `brochures-index.json` to find public GitHub and raw URLs for brochure files.

Agents may use these public URLs for PDF, image or brochure review. Any durable extraction into sources, evidence, claims, todos or product research must happen in the private `markvanderpoel/Verduurzaming` repository according to its workflow rules.

If a public brochure conflicts with canonical data in the private repository, the private canonical data and evidence records win.
